# Privacy

**PcHealthCheck has no telemetry, no crash reporting, and no phone-home. Ever.**

- **Every health check works fully offline.** No check in this app contains network code — the CI build fails if any assembly other than `PcHealth.Net.Optional` so much as mentions `System.Net`. A scan makes zero connections, and the receipt after every scan says so.
- Scan results exist only in memory until **you** export them, via a save dialog, to a location you choose (HTML or JSON). Nothing is uploaded anywhere.
- The app never reads the contents of your documents, photos, or personal files. Startup-item checks read program binaries only (to verify signatures and compute hashes).
- The System overview check lists the **five programs holding the most memory and the five that used the most processor time**, by program name only, for example "brave ×29 5.5 GB". It never includes paths, window titles or command lines. Like the startup program names, these appear in the report and travel with it if you share it.
- The app never modifies your system. The only file it writes during a scan is a temporary battery report inside its own folder, which is deleted after parsing — and shown in the post-scan receipt.
- Administrator rights are requested only if you select an admin check, and only for a separate short-lived helper process that exits when the scan ends. The main window never runs elevated. The helper reads drive health, backup configuration, and platform security settings — it never reads your files, and never reads BitLocker recovery keys or product keys into a report.
- **One exception to "never modifies your system":** the "Temperatures & fans" check loads a kernel-level driver, because CPU and motherboard sensors cannot be read any other way. It is opt-in, carries its own **LOADS DRIVER** badge, and the elevated helper asks you about it separately in its own dialog — declining just leaves temperatures out of the report. The driver is used to read sensor values only; the app never sets fan speeds, clock rates, or voltages.
- **Optional tool installs are consented twice and reversible.** If a reading needs an extra tool, the app shows the exact command before running it (plus the UAC prompt), and records that *it* installed the tool. When you close the app it offers to remove what it installed — after checking the tool wasn't already on your PC and that no running program is using it — and logs the removal with the reinstall command in `dependency-history.txt` (kept 15 days). The app never removes anything it did not install.
- **There is exactly one feature that uses the internet: the VirusTotal second opinion**, and it never runs by itself. It needs your own free API key, typed in each time — the app never stores it and none is built in. Before anything is sent, a dialog lists every fingerprint that would leave the machine, in full. What is sent is a SHA-256 fingerprint per file and nothing else: **your files are never uploaded**, so their contents stay here. A fingerprint does tell VirusTotal that this PC holds a file with those exact bytes, which is why the list is short, capped, and shown to you first. The receipt then reports how many lookups were actually made, counted by the app rather than promised.
- **On-demand malware scans** (the "Quick scan" and "Scan a folder" buttons) ask Windows Defender to do the work; the app makes no connection of its own. Defender's own cloud protection may contact Microsoft during a scan, exactly as it would for a scan you started from Windows Security — the consent dialog says so before you agree. A folder scan runs with remediation switched off, so Defender reports what it finds and moves nothing; a quick scan lets Defender act on what it finds using your normal settings.
- Consent choices are stored locally in `%APPDATA%\PcHealthCheck\consent.json`. Delete it anytime to reset every choice to OFF.
- Trend history is stored locally in `%LOCALAPPDATA%\PcHealthCheck\history.db`. It holds only measurement names, the drive or volume they belong to, and numbers — enough to notice that a failure counter is growing, and nothing else. It never leaves the machine. Switch it off with the checkbox on the main screen (or `--no-history`), erase it with the **Delete history** button, or simply delete the file. Every scan tells you in the receipt exactly how many measurements it recorded.
- **The laptop audit kit** (`1 - Check this laptop.cmd`, for checking company laptops before handover) reads more than the app itself:
  - the laptop's **serial number**, to name its result file, plus its BIOS version, memory slots and disk types;
  - your answers to its questions about the laptop's physical condition.

  Everything stays in one zip on your USB stick, and the kit lists the zip's contents before you send it anywhere. The app itself still never reads a serial number. The kit removes the app's own folder from the laptop again if the run created it.
- **Windows 11 readiness** is read from the verdict Windows keeps in its registry (the same compatibility check Windows Update uses). Nothing is sent anywhere to get it.
- **Linux checks (in development, not in any release yet).**
  - They read only files under `/proc`, `/sys` and `/etc/os-release`. They run no program, write no file and need no root.
  - The battery's serial number is never read.
  - Network filesystems (NFS, SMB, SSHFS) are never asked for their free space, because asking would make a connection.
  - The report lists your disks by mount point, which can include your user name (for example `/media/<you>/<drive>`), and the computer's maker and model, never its serial number.
- Verify us: run a scan with Wireshark or GlassWire open — you will see zero connections from this app. (Start a VirusTotal lookup and you will see exactly the connections that dialog told you about, and no others.) The receipt panel after each scan lists every process spawned, every file written, and every lookup made.
